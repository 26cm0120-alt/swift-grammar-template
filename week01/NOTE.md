## 1. 教材コードで読めたこと（3行）

`let` は値を変更しない定数、`var` は値を変更できる変数を宣言するときに使う。Swiftでは `Int` と `Double` の間で暗黙的な型変換が行われないため、必要に応じて明示的に変換する。条件分岐には `if` 文や `switch` 文を使い、`switch` 文では `case` ごとに処理を書く。

## 2. 演習の記録（4点セット）

### 演習1：合格者の名前を配列に集める

```swift
for i in 0..<names.count {
    if scores[i] >= 60 {
        passers.append(names[i])
    }
}
```

**使ったプロンプト：**

「Swift で、names（[String]）と scores（[Int]）が同じ並びであります。scores が60以上の人の names だけを、順番を変えないで passers に集めるコードを、for と if で書いてください」

**AIの出力から自分が変えた点：**

変更していない。`>= 60` は「点数が60点以上か」を判定しており、課題の条件と一致しているため。

**自分の言葉での説明（何を受け取り、何をして、何を返す）：**

`names` と `scores` の配列を受け取り、同じ添字の名前と点数を順番に調べる。点数が60点以上なら、その名前を `passers` に追加する。このコード自体は値を返さず、`passers` を更新する。`names` と `scores` は同じ人数分のデータである必要がある。

**壊す実験（何を変えたら、何が起きたか）：**

`>= 60` を `> 60` に変えると、60点の人が `passers` に入らなくなる。`passers.append(names[i])` を消すと、条件に合う名前が見つかっても配列に追加されない。

### 演習2：80点以上の人数を数える

```swift
for (name, score) in scoreOf {
    if score >= 80 {
        highScorers += 1
    }
}
```

**使ったプロンプト：**

「`scoreOf` を回して、80点以上の人数を `highScorers` に入れるSwiftコードを書いてください。」

**AIの出力から自分が変えた点：**

辞書のキーを表す変数名を `names` から `name` にした。1人分の名前を表す変数なので、単数形のほうが意味が分かりやすいから。名前自体は人数を数える処理では使っていない。

**自分の言葉での説明（何を受け取り、何をして、何を返す）：**

`scoreOf` という辞書から名前と点数を1組ずつ取り出す。点数が80点以上なら `highScorers` を1増やす。すべて調べ終わると、`highScorers` に80点以上の人数が入る。このコードは人数を返すのではなく、変数を更新する。

**壊す実験（何を変えたら、何が起きたか）：**

`score >= 80` を `score > 80` に変えると、80点ちょうどの人が数えられなくなる。`highScorers += 1` を消すと、条件に合う人がいても人数が増えず、初期値のままになる。

### 演習3：点数の合計と平均を計算する

```swift
for score in scores {
    total += score
}

average = Double(total) / Double(scores.count)

print("合計：\(total)")
print("平均：\(average)")
```

**使ったプロンプト：**

「`scores` の合計を `total` に、平均を `average` に入れるSwiftコードを書いてください。」

**AIの出力から自分が変えた点：**

変更していない。合計を求めた後、`total` と `scores.count` を `Double` に変換しているため、小数を含む平均を計算できるから。

**自分の言葉での説明（何を受け取り、何をして、何を返す）：**

`scores` から点数を1つずつ取り出して `total` に加える。その後、合計を人数で割って平均を求め、`average` に保存する。最後に合計と平均を画面に表示する。`Double` に変換することで、平均の小数部分を失わずに計算できる。

**壊す実験（何を変えたら、何が起きたか）：**

`Double(total) / Double(scores.count)` を `total / scores.count` に変えると、整数同士の割り算になり、小数部分が失われる可能性がある。また、`scores` が空の場合は人数が0になるため、平均を計算できない。

### Q1

**質問：**

`>= 60` を `> 60` に変えると、どのような違いがありますか？

**AIの回答の要点：**

`>= 60` は60を含む「60以上」を表し、`> 60` は60を含まない「60より大きい」を表す。

**自分の理解：**

### Q2

**質問：**

`Double` に変換せずに合計を人数で割ると、平均の小数部分が失われることがありますか？

**AIの回答の要点：**

整数型同士の割り算では結果も整数として扱われるため、小数部分が切り捨てられる。`Double` に変換すると小数を含む計算になる。

**自分の理解：**

平均を正確に表示するには、割り算の前に少なくとも一方を `Double` に変換する必要があると理解した。

### Q3

**質問：**

`passers.append(names[i])` の行を消すとどうなりますか？

**AIの回答の要点：**

条件を満たす名前を見つけても、`passers` に追加する処理がなくなるため、`passers` は空のままになる。

**自分の理解：**

`if` 文は条件を判定するだけで、配列に値を入れるには `append` が必要だと分かった。
