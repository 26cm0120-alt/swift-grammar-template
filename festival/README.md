## 何ができるアプリか（3行）
古典的な3DダンジョンRPG(ウィザードリィ風)の探索を擬似的に体験できます。画面上のボタンでプレイヤーの方向転換や前進を操作し、前方の壁の確保を確認できます。画面下部にある2Dミニマップで自分の歩行とゴールまでの経路を入力して確認できます。
